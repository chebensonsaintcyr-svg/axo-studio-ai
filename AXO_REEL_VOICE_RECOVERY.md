# AXO narration recovery

If the narration panel reports that the server setup is incomplete, repeating the request will not repair it. Check the service configuration in the provider dashboard with authorized access, then refresh the AXO page after the correction.

Download any completed audio previews before refreshing: the current previews live only in the browser session and are not stored in the account.
